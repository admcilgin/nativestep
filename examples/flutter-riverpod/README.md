# Basket (Flutter, Riverpod)

The first migration input for nativestep (PLAN.md M5): sign-in, a product list, product details and a basket,
built with `flutter_riverpod`, `dio` and `go_router`.

The API host (`api.basket.example`) does not exist. The app is meant to be driven by nativestep with fixtures;
without them every request fails with "Could not reach the server".
